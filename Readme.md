# Day 03: Mathematical Rose Curves (Maurer Rose) 🌹

A visual representation of mathematical polar equations generating an intricate, web-like geometric rose with vibrant neon RGB color shifting.

## Project Specifications
- **Language:** Python 3.8+
- **Libraries:** `turtle`, `math`, `colorsys`
- **Resolution:** 540x960 (9:16 Reel Format)
- **Runtime:** ~15-18 Seconds

## Execution Commands
```powershell
python .\maurer_rose.py
